### AI로 나만의 3d영상을 만들어봐요

## 단계별 학습

1단계: 프롬프트를 통해 이미지모델과 힉스필드를 사용해봐요. AI이미지 모델의 종류를 알아봐요

2단계: 보다 나은 프롬프트를 쓰는 법을 공부해요. 옷, 음식, 인물 등에 따라서 나눠 써요. 

3단계: 힉스필드로 여러 컷/비트로 이루어진 영상을 만들어요. 씬별 기획을 배워요.

4단계: 3단계 + 효율적으로 실험하는 방법을 배워요. 힉스필드를 Runway와 비교해봐요.

5단계: 클로드 코드 + 블렌더(previz) + 힉스필드 워크플로를 체험해요. 그냥 따라만 해봐요.

6단계: 5단계 + 조금 디테일하게 잡는 법을 알려드려요. (카메라 구도, 렌즈, 빛, 후보정 관련 스킬) -> 여기서부턴 어려워요

7단계: 6단계 + 인물 디테일 코스예요. 빠른 움직임, 정교한 표정과 립싱크, 실제 사진과 목소리를 쓰는 법, 캐릭터 일관성을 다뤄요

8단계: 7단계 + artcraft mcp사용법. 프로젝트 export해서 실제 영상 전문 프로덕션 팀에서 활용할 수 있게 해요.
